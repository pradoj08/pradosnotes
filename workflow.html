The same container lookup explained all at once.

HTML / input & structure

The field holds
the question.

HTML provides the search field, status dropdown, six container records, and result area. A field can accept text without knowing how to find a matching container.

JavaScript / processing

The rule finds
the answer.

JavaScript reads the search criteria, compares each record, hides nonmatches, and updates the count and location. It decides which records satisfy the search.

CSS / presentation

The design makes
the answer readable.

CSS aligns the controls, separates the result from the table, and gives recorded statuses their visual treatment. It does not decide which container matches.
